# 💳 Desafio: Sistema de Conta Bancária em Python

## 📌 Descrição

Este desafio consiste em criar um pequeno sistema de **conta bancária** utilizando **Programação Orientada a Objetos (POO)** em Python.

O objetivo é praticar conceitos fundamentais de POO, como:

* criação de **classes**
* uso de **atributos**
* definição de **métodos**
* criação e manipulação de **objetos**

---

## 🧠 Conceito do exercício

O programa deve representar uma **conta bancária** que possui um titular e um saldo.
A conta deve permitir operações básicas como:

* consultar saldo
* depositar dinheiro
* sacar dinheiro

Essas operações são implementadas através de **métodos da classe**.

---

## ⚙️ Estrutura do programa

O sistema deve possuir uma classe chamada **Conta**, contendo:

### Atributos

* `titular` → nome do dono da conta
* `saldo` → valor disponível na conta

### Métodos

**mostrar_saldo()**

Retorna uma mensagem mostrando o saldo atual da conta.

Exemplo:

```
Barbara, seu saldo é 700
```

---

**depositar_valor(valor)**

Adiciona um valor ao saldo da conta.

Exemplo:

```
saldo = saldo + valor
```

---

**sacar_valor(valor)**

Remove um valor do saldo da conta.

---

## 🧪 Exemplo de funcionamento

Fluxo esperado do programa:

1. Criar uma conta com titular e saldo inicial.
2. Exibir o saldo.
3. Depositar um valor.
4. Exibir o saldo atualizado.
5. Realizar um saque.
6. Exibir o saldo novamente.

---

## 🎯 Objetivo do desafio

Este exercício tem como finalidade ajudar a compreender:

* como **modelar objetos do mundo real em código**
* como **alterar o estado de um objeto**
* como **organizar código utilizando POO**

Ele é um passo importante para aprender a estruturar programas maiores e mais organizados em Python.
